# Security Policy

We take the security of BakaTracker seriously. If you believe you have found a security vulnerability, please report it to us responsibly as outlined below.

---

## Supported Versions

Only the latest stable release of BakaTracker is actively supported with security updates:

| Version | Supported |
| :--- | :--- |
| **1.0.x** |  Active |
| **< 1.0.0** | ❌ No |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please send an email to the project maintainer or owner with details of the vulnerability.
- Include a description of the issue.
- Provide step-by-step instructions or proof of concept to reproduce.
- Note any potential impacts.

We will acknowledge receipt of your report within 48 hours and coordinate a fix and release timeline before public disclosure.
