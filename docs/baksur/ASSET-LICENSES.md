## 1. Bloub — code license

**FACT.** Bloub (`https://github.com/jeremy-prt/bloub`, by Jérémy Perret)
is licensed **MIT**:

> `MIT License — Copyright (c) 2026 Jérémy Perret`

Standard MIT grant: use, copy, modify, merge, publish, distribute,
sublicense, sell — **condition: retain the copyright + permission notice**.

**FACT.** README carries an explicit scope disclaimer:

> "The MIT licence covers the code in this repository, not the design it
> imitates." — and the project is "Not affiliated with, endorsed by or
> connected to x.ai."

### Consequences for BakaTracker

| Item | Verdict |
|---|---|
| Vendoring Bloub's `src/bot/` TS modules (math, repere, shape, face, expressions, states, engine, decor) | **PERMITTED** — MIT, with attribution (see §4) |
| Porting `BloubBot.vue` logic to a React component | **PERMITTED** — derived work of MIT code |
| Trimming `states.ts` to 5 states, trimming `decor.ts` | **PERMITTED** — modification is a MIT right; keep the notice |
| Claiming Bloub's *default look* (black circle + white capsule eyes à la x.ai bot) as Baksur | **NOT PERMITTED / DO NOT** — MIT does not convey the imitated design's rights; trade-dress/trademark risk lives with x.ai. Baksur must diverge (see [CHARACTER.md](./CHARACTER.md) distinctness table) |
| Using Bloub's name/logo in BakaTracker UI | **DO NOT** — refer to it in docs/notices only |
