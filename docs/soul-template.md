# BakaSur Soul Template

> **What is a Soul?** Your Soul is a markdown document that gives BakaSur
> persistent knowledge about you — your goals, work style, preferences, and
> current context. BakaSur reads it at the start of every conversation so it
> can personalize responses without you repeating yourself.
>
> **Where is it stored?** Your Soul is stored securely in your BakaTracker
> account (server-side, per-user). It is never shared with other users.
>
> **Security:** Never include passwords, API keys, tokens, or any secret
> credentials in your Soul. Treat it as a public-facing profile about yourself.
